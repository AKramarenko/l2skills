Формулы расчёта

Задача: для каждого уровня +n определить, выгоднее использовать обычную или мастери книгу, учитывая что все предыдущие уровни заточены оптимально (стоимость = E_opt(n-1)).

Стоимость шага обычной книгой (фейл → сброс в 0, нужно заново):
S_обычн(n) = (E_opt(n-1) + C_обычн(n)) / p(n) − E_opt(n-1)
= C_обычн(n) / p(n) + E_opt(n-1) · (1 − p(n)) / p(n)
Включает «цену риска»: чем дороже уже вложено, тем больнее потерять.

Стоимость шага мастери книгой (фейл → уровень не падает):
S_мастери(n) = C_мастери(n) / p(n)
Не зависит от предыдущих вложений — риска потери нет.

Оптимальный выбор:
E_opt(n) = E_opt(n-1) + min(S_обычн(n), S_мастери(n))

Точка переключения: обычная выгоднее пока E_opt(n-1) невелика.
Как только накопленная стоимость делает «цену риска» слишком высокой — мастери выгоднее.

Стоимость попытки:
C_обычн(1) = codex + адена(1), C_обычн(n>1) = адена(n)
C_мастери(n) = mastery + адена(n) × 5
